| `CONN-CAMUNDA-MCP-R009.1` | **Declare the instance machine and its transition function.** Subsystem: connector lifecycle. The state set is closed; Completed, Canceled and Terminated are terminal. Incident is a sub-state of Active: it has Active as its parent, accepts every event Active accepts except RaiseIncident, and returns to Active on ResolveIncident. Caller chain: the guarded instance operations of R009.3 call `instance_transition`. Shape: pure enums and one closed table; no I/O. Depends on: none.
